The goal was a desk clock that also plays audio over Bluetooth. The **ESP32** is
perfect for this: dual-core, Wi-Fi and Bluetooth built in, and cheap enough that
frying one during prototyping doesn't hurt.

## The display

The dot-matrix display was the fiddly part. Timing the multiplexing so the digits
stay bright without flicker took a few iterations:

```cpp
// Refresh one column at a time, fast enough that the eye sees a full frame
for (uint8_t col = 0; col < COLS; ++col) {
    shiftOutColumn(col, frame[col]);
    delayMicroseconds(200);
}
```

## Two cores, no stutter

Running the audio stack on one core while the display refreshes on the other kept
everything smooth. More build notes — and the full schematic — coming soon.
