Fedora ships recent Wayland bits, which makes it a great base for a
scrolling/tiling setup. I run **Sway** most days and **Niri** when I want its
infinite-strip workflow; both read almost the same config habits.

## The glue is small

- `foot` for the terminal
- a status bar and a launcher
- a couple of shell scripts for screenshots and clipboard

It's all in my dotfiles, so a new laptop is one clone away from feeling right.
